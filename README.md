# Memory Cards Trainer

Однофайловый статический сайт для Vercel.

## Как залить

1. Распакуй архив.
2. Загрузи файл `index.html` в GitHub-репозиторий.
3. В Vercel выбери этот репозиторий.
4. Framework Preset: Other.
5. Build Command, Output Directory и Install Command оставь пустыми.
6. Нажми Deploy.

В этой версии CSS, JS и данные встроены прямо в `index.html`, поэтому стили не сломаются из-за отсутствующих папок `assets` или `data`.
