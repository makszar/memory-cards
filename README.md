# Memory Cards Trainer

Статический тренажер карточек для Vercel.

## Режимы

- Перевод: русская фраза на лицевой стороне, английский перевод на темной стороне.
- Определения: термин на лицевой стороне, определение на темной стороне.
- Аббревиатуры: аббревиатура на лицевой стороне, расшифровка на темной стороне.

## Управление

- Клик или тап по карточке: переворот.
- Свайп справа налево: не знаю.
- Свайп слева направо: знаю.
- Mix: перемешать текущую колоду.
- Вернуться к прошлой карточке: откатить последний ответ.

## Деплой на Vercel

Залей папку в GitHub, потом импортируй репозиторий в Vercel с пресетом Other. Build Command и Output Directory оставь пустыми.
